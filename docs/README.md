## O kameře

AMASC01 je All-Sky kamera určená pro:
- Astronomická pozorování
- Sledování meteorů a blidů
- Monitoring světelného znečištění
- Meteorologická pozorování
- Zachycení přechodných jevů na obloze

## Technické specifikace

- Zorné pole: 180° (celá obloha)
- Citlivost: Optimalizováno pro noční pozorování
- Rozlišení: Závisí na konfiguraci kamery
- Rozhraní: USB/Síťové připojení
- Formáty výstupu: FITS, JPEG, PNG
