# AMASC01 - AstroMeters.eu AllSky Camera

AMASC01 je All-Sky kamera od AstroMeters.eu určená pro sledování celé oblohy v reálném čase. Kamera je navržena pro astronomické aplikace, meteorologické pozorování a monitoring světelného znečištění.

## Funkce

- **Celoplošné pokrytí oblohy**: 180° zorné pole pro sledování celé oblohy
- **Vysoká citlivost**: Optimalizováno pro noční pozorování
- **Automatické ovládání**: Podpora automatického řízení expozice a zisku
- **Odolná konstrukce**: Vhodná pro venkovní instalaci
- **Open-source software**: Komunitou podporované nástroje a skripty
